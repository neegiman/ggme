# 임시 규칙 v1 · 3~8명

`three_player_web_games_design_v1.md` 원문을 받지 못해 적용한 규칙입니다. 원문 규칙과의 일치는 검증되지 않았으며, 화면에도 임시 규칙임을 표시합니다. 3인용 v0의 점수는 유지하고 인원·투표를 일반화했습니다.

## 공통

- 참가자 N은 3~8명이며 생성자도 참가할 수 있습니다.
- 라운드마다 독립적으로 배정합니다. 이전과 같은 역할·단어가 나올 수 있습니다.
- 투표는 자신을 제외한 한 사람에게 합니다. 생성자가 N표를 모두 입력합니다.
- **단독 최다 득표자를 지목합니다.** 과반수일 필요는 없습니다. 최다 득표 동률이면 정체를 찾지 못한 것으로 처리합니다. 3명의 1:1:1도 같은 경우입니다.
- 시간 초과 후 생성자가 수동 판정하며 자동 승패·기권은 없습니다.
- 단어·장소 정답은 NFKC 정규화 후 공백 제거·영문 대소문자 무시로 정확히 비교합니다. 동의어·부분 일치는 인정하지 않습니다.
- 판정 전 입력을 수정할 수 있습니다. 저장 후 점수 수정은 제공하지 않습니다.

## 라이어

라이어 1명은 자기 역할과 카테고리만 받습니다. 시민 N−1명은 카테고리와 같은 단어를 받습니다.

| 상황 | 승리 | 점수 |
| --- | --- | --- |
| 오지목 또는 최다 득표 동률 | 라이어 | 라이어 +3, 시민 각각 0 |
| 라이어 지목 후 단어 추측 정답 | 라이어 | 라이어 +3, 시민 각각 0 |
| 라이어 지목 후 단어 추측 오답 | 시민 | 시민 각각 +2, 라이어 0 |

지목된 참가자에게 마지막 단어 추측을 요청합니다. 결과 전에는 생성자에게 해당 참가자의 정체를 표시하지 않습니다. 추측 포기는 ‘모름’으로 입력합니다.

## 스파이

스파이 1명은 자기 역할만 받습니다. 시민 N−1명은 같은 장소와 자기 직업을 받습니다. 장소별 직업은 중복될 수 있습니다.

| 상황 | 승리 | 점수 |
| --- | --- | --- |
| 투표 전 장소 추측 정답 | 스파이 | 스파이 +3, 시민 각각 0 |
| 투표 전 장소 추측 오답 | 시민 | 시민 각각 +2, 스파이 0 |
| 추측 없이 투표로 스파이 지목 | 시민 | 시민 각각 +2, 스파이 0 |
| 추측 없이 오지목 또는 최다 득표 동률 | 스파이 | 스파이 +3, 시민 각각 0 |

스파이는 투표 전에만 장소를 한 번 추측할 수 있습니다. 스파이임을 밝히고 말한 답을 생성자가 기록합니다. 투표 후 추가 장소 추측은 없습니다.

## 금지어

모두 서로 다른 단어 하나씩을 배정합니다. 개인 카드에는 다른 N−1명의 이름·금지어만 담고 자기 단어 배정은 제외합니다.

금지어와 정확히 같은 발언은 위반 1회입니다. 조사·어미가 붙은 표현도 포함하되 의미가 다른 단어의 일부는 제외합니다. 참가자들이 동의한 횟수를 생성자가 수동 기록합니다. 자동 음성 인식·감지는 없습니다.

점수는 `max(0, 3 - 위반 횟수)`입니다. 최고 점수자가 승리하고 동점은 공동 승리입니다. 모두 0점인 경우도 공동 승리입니다. 위반 입력은 0~99회이며 적발자 추가 점수·탈락은 없습니다.

## 호환성과 원문 확인

기존 3인 저장 기록과 카드 링크를 계속 읽습니다. 기존 기록에는 `provisional-v0`, 새로운 기록에는 `provisional-v1`을 남깁니다. 3인 점수·승패는 이전과 같습니다.

원문 확보 후 승리 점수·투표 동률·라이어 마지막 기회·스파이 추측 시점과 오답 처리·금지어 발언 인정 범위를 대조해야 합니다. 4~8명 규칙은 확장판 규칙입니다.
