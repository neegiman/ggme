# 검증 보고서

검증일: 2026-10-12. 규칙: **provisional-v1**, 참가자 **3~8명**.

## 확인 범위

- Node.js 테스트 28개 통과: 모든 3인 유효 투표 조합, 3~8명 모든 특수 역할 자리, 단독 최다 득표·동률·오지목·추측 정답/오답·금지어 점수·중복 저장 방지.
- 3~8명 각각 세 게임의 역할·허용 데이터·고유 개인 링크·다음 라운드 재발급 및 저장 복원을 검사했습니다. 확장된 무작위 카드 검증 180라운드와 기존 90라운드를 포함합니다.
- 이전 카드 v1과 저장 스키마 v1을 읽고 3인 점수·완료 기록·라운드 ID를 유지하는 것을 확인했습니다.
- Chromium·WebKit의 **3명 및 8명** 전체 흐름: 생성 → 서로 저장소를 공유하지 않는 참가자 컨텍스트의 모든 카드 → 표시·숨김 → 전달 체크 → 타이머 → 수동 판정 → 결과 → 새로고침 → JSON 내보내기 → 다음 라운드 → 새 멤버.
- 실제 클립보드 복사는 Chromium에서 검사했습니다. 공유는 실제 메시지를 보내지 않고 모의 API의 개인 URL을 검사했습니다.
- `/ggme/`에서 링크가 `/ggme/card.html#…`로 생성되는 것을 검사했습니다.
- 시작 화면 320/360/390/430/768/1280px, 진행·카드 화면 320/390/430px에서 가로 넘침과 44px 터치 영역을 검사했습니다. 최대 길이 한글·영문·이모지 이름도 확인했습니다.
- 숨김 시 비밀 DOM 제거, 앱 전환 이벤트, 자기 단어 배정 미포함, 스파이 장소·라이어 단어 미노출을 확인했습니다.
- 타이머 일시정지·시간 경과·새로고침·초기화, 누락 투표·자기 투표·중복 이름·링크 손상·XSS 텍스트·저장소 손상/차단·점수 중복 방지를 검사했습니다.

기계 판독 결과와 Chromium 화면은 `test-artifacts/report.json`, `test-artifacts/*.png`에 생성하며 Git 및 배포에서 제외합니다. `npm test`, `npm run test:browser`로 재현할 수 있습니다.

## 한계

첨부 설계서 원문 대조와 실제 iPhone Safari·Android Chrome 기기 검증은 미완료입니다. 모바일 엔진 에뮬레이션은 물리 기기를 대체하지 않습니다. 실제 참가 기기들로 공유 시트·키보드·앱 전환·링크 재전달을 확인해야 합니다.

WebKit의 Playwright 화면 캡처는 인라인 스타일 삽입 때문에 CSP에 차단됩니다. CSP를 유지하면서 WebKit 기능·DOM 레이아웃을 검사하고 픽셀 캡처는 Chromium에서 수행합니다.

GitHub Pages 공개 배포 성공: https://neegiman.github.io/ggme/ (HTTPS). 저장소: https://github.com/neegiman/ggme. GitHub Actions의 Game logic tests 및 pages build and deployment가 성공했습니다. 공개 주소에서 Chromium 통합 테스트를 다시 실행하여 3명·8명 전체 카드 흐름과 3~8명 전체 생성자 흐름이 통과했고 콘솔 오류·외부 요청은 0이었습니다.

추가 검증: Chromium·WebKit 모두 4/5/6/7명으로 세 게임을 연속 진행하며 단독 최고 득표 동률 처리·결과·다음 게임·통산 기록을 확인했습니다. 인원 선택을 줄였다 늘려도 입력한 이름이 유지되고 새 그룹에서는 인원 선택이 유지됩니다. 최종 브라우저 콘솔 오류 0, 외부 요청 0입니다.
